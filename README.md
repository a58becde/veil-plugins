# Каталог плагинов Veil

Плагины для ботов [Veil](https://github.com/a58becde/veil-client): их видят и ставят владельцы ботов командой
`/market` — и у своего бота, и у бота в пуле. Плагин работает в движке WebAssembly (отдельный процесс без файлов и
ключей бота, без сети, только с разрешениями, которые подтвердил владелец) — устройство и форматы: [`docs/MARKET.md`](https://github.com/a58becde/veil-client/blob/main/docs/MARKET.md)
клиента, как написать плагин — [`docs/PLUGINS.md`](https://github.com/a58becde/veil-client/blob/main/docs/PLUGINS.md).

## Что здесь лежит

| Путь | Что |
|---|---|
| `index.json` | все плагины каталога и отозванные сборки (`seq` растёт с каждым изменением) |
| `index.json.sig` | подпись индекса ключом каталога |
| `packages/<id>/<version>.zip` | пакеты; рядом `.zip.sig` — подпись автора |
| `packages/<id>/<version>.zip.enc` | платные пакеты, зашифрованные ключом версии: прочитать их может только бот с лицензией |

Бот скачивает индекс целиком и проверяет подпись каталога, затем у пакета — размер, SHA-256, подпись автора, что
сборка не отозвана и что манифест совпадает с индексом. Обновление, подписанное другим ключом автора, бот не ставит.

## Как добавить свой плагин

Добавить плагин может любой, бесплатный или платный (цена в Telegram Stars). Пошагово — **[DEVELOPING.md](DEVELOPING.md)**:
пакет и ограничения движка, проверка без бота и сервера (`python -m veil.plugin_dev`), проверка в своём боте, ключ
автора, упаковка и подпись, подача (бесплатный — pull request, платный — архив лично владельцу каталога), обновления.

## Что проверяет ревью

- Код прочитан целиком: нет обфускации, `exec`/`eval` строк, загрузки кода из сети, попыток выйти из движка или
  обмануть владельца бота (кнопки, похожие на кнопки бота, просьбы прислать 12 слов или токен).
- Пакет проходит проверку в движке: `python -m veil.plugin_dev <пакет> --script=…` без сбоев.
- Разрешения минимальны и объяснены. Чувствительные (`private`, `published`, `before_send`) — только когда без них
  никак; чувствительное вместе с `net` — только с убедительной причиной: такой плагин может унести текст анонимного
  поста вместе с IP машины пользователя.
- Хосты `network` — домены сервиса, ради которого плагин существует; никаких «сборщиков» и сокращателей ссылок.
- Обновление: прочитана разница с прошлой версией, ключ автора тот же.
- Описание честное, цена указана; платный пакет прислан не через публичный pull request.
